# WebDev-L2-TributePage : Ada Lovelace

## Objectif
Page hommage à Ada Lovelace (1815–1852), mathématicienne considérée comme la première personne à avoir conçu un algorithme destiné à être exécuté par une machine. Réalisée dans le cadre du stage OIBSIP, piste Développement Web, Niveau 2.

## Stack
- HTML5
- CSS3 (sans JavaScript)

## Fonctionnalités
- Titre plein écran avec portrait, dégradé de superposition et slogan
- Image libre de droits (domaine public), hébergée sur Wikimedia Commons : *[Ada Lovelace portrait.jpg](https://commons.wikimedia.org/wiki/File:Ada_Lovelace_portrait.jpg)*, aquarelle d'Alfred Edward Chalon (v. 1840)
- Section biographie : 4 paragraphes de contenu original, paraphrasé à partir de sources publiques (aucun copier-coller)
- Chronologie des dates marquantes (naissance, rencontre avec Babbage, publication de 1843, mort, hommage posthume via le langage Ada)
- Bloc citation mis en valeur (bordure d'accent, typographie italique)
- Deux couleurs de fond distinctes selon les sections : parchemin clair pour la biographie/citation, bleu encre foncé pour la chronologie
- Deux familles de police : `Playfair Display` (titres, avec repli sur `Georgia`) et `Segoe UI` (corps de texte)
- Mise en page entièrement adaptative (points de rupture à 700px et 480px)

## Lancer le projet
Aucune dépendance ni build requis.

```bash
start index.html   # Windows
```
